Year 1 of Professional Development

Module 2

I this module i really started to make ProfDev help me to add skills to my toolset. I used this time to learn soldering and eventually fixed a device with my newfound skill. I eventually used this skill in many other projects, proving this was time well spent.

Module 3

In this module i found one of biggest passions which was building a smart home and automation. I learned many different skills in this time such as: flashing a Raspberry Pi, Making my own smart devices with ESP32, and how to us the Home Assitant open source project.

Module 4

In this module i learned to use 2 different machines and how to measure things to design around them. Specifically i learned to use a laser cutter and 3D printer. I designed the CAD models using Autodesk Fusion and used components that i measured and recreated in CAD.
